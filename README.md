# Robot vs Monsters (PyGame)
**Capstone Graduation Project** - University of Helsinki *Advanced Programming with Python*

A 2D arcade game built with Python and Pygame. 
The player controls a robot dodging monsters while collecting coins to reach the escape door.

## How to play
1. Make sure you have python and pygame installed (`pip install pygame`).
2. Run `python main.py`
3. Use the arrow keys to move the robot.
